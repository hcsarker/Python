# Chapter 04 - Syntax Analysis (Python)

There is one Python file for each section: 4.1.py through 4.9.py.

## How to run
1. Install Python 3.
2. Open Command Prompt/Terminal in this folder.
3. Run one file, for example:
   python 4.4.py

## Important
The supplied DOCX lists section topics and exercise types, but it does not provide
a unique grammar/input for every exercise. Therefore each file uses small,
clearly labeled example grammars to demonstrate the corresponding topic.
The Section 4.6 file demonstrates LR(0) closure/GOTO concepts, not a complete
general-purpose SLR table generator. Section 4.9 is a Python learning version
of Yacc/Bison-style calculator/parser tasks, not an actual Yacc/Bison file.
